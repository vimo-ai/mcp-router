## Features

- **One Endpoint** — Connect once, route to all MCP servers
- **Workspace Isolation** — Different projects, different server combos
- **Smart Routing** — Load tools on demand, save tokens
- **Auto Integration** — One click to configure Claude Code & Codex

## Quick Start

```bash
# Clone and build
git clone https://github.com/vimo-ai/mcp-router.git
cd mcp-router && ./scripts/build-core.sh

# Open in Xcode
open mcp-router.xcodeproj  # Cmd+R
```
